# Ice Ih Cubic Box REMD Fixture

This directory contains the repository-local input fixture used by the REMD
performance benchmark.

The fixture includes only the files needed to run the benchmark:

- `ice_Ih_cubic_8064w_*.txt` topology and parameter inputs
- `pre_eq/pre_eq_coordinate.txt`
- `pre_eq/pre_eq_velocity.txt`

Large pre-equilibration outputs and trajectories are intentionally not stored
here.
